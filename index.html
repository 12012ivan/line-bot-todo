待辦小幫手

LINE Bot 第一版｜開發紀錄與測試

專題介紹

本專題嘗試製作一個待辦小幫手，讓使用者用簡單文字指令記錄待辦事項，並在輸入不完整或不支援的內容時收到提示。

使用對象：想快速記下待辦事項的人。

目前狀態：已完成在電腦命令提示字元執行的 Python 測試版本，尚未連接 LINE。

核心功能與操作示範

  • 輸入 record: 星期五交報告，程式回覆已記錄的待辦。
  • 輸入 record:，程式提醒使用者補上待辦內容。
  • 輸入其他文字，程式顯示使用提示。
  • 輸入 quit，程式結束。

正常輸入：使用者輸入「record: 星期五交報告」→ Bot 回覆「Bot: Recorded - 星期五交報告」。

不完整輸入：使用者輸入「record:」→ Bot 回覆「Bot: Please enter a task.」。

開發過程

  1. 規劃待辦記錄、空白輸入提醒和不支援輸入提示。
  2. 使用 Python 完成命令提示字元測試版本。
  3. 測試正常輸入、空白輸入和不支援的輸入。
  4. 將程式與 README 說明放到 GitHub。

AI 協作與檢查

使用工具：AI 對話工具協助整理開發步驟、README 說明和本頁內容。

代表性指令：「請依照我的待辦 Bot 專題資料，整理一頁開發紀錄網頁，包含介紹、操作示範、開發過程、AI 協作、測試結果與限制；缺少的資料請標示待補，不要編造。」

我的檢查：比對網頁內容與程式目前功能，並在命令提示字元實際輸入指令測試。

測試結果

請依命令提示字元的實際測試畫面，確認並補上「實際結果」；不要只用預期結果代替測試證明。

  • 正常輸入：record: 星期五交報告｜預期：顯示已記錄內容｜實際結果：請依測試畫面填寫。
  • 空白內容：record:｜預期：提醒補上待辦｜實際結果：請依測試畫面填寫。
  • 不支援輸入：hello｜預期：顯示使用提示｜實際結果：請依測試畫面填寫。

實測截圖：請在此處補上命令提示字元測試畫面，作為實測證明。

心得、限制與下一步

我學到如何用文字指令處理不同輸入，也了解測試時需要同時檢查正常、空白和不支援的情況。

目前程式只在命令提示字元執行，尚未連接 LINE，也沒有永久儲存待辦。下一步可改善輸入提示，並研究如何連接 LINE。
